## Unreleased — 组件化 PoC 候选版本

- 增加无 UI 审计容量状态、80% 容量预警和离线 `export-audit`；容量不足保持失败关闭，并在原留存规则允许回收后恢复。真实 I/O 故障继续隔离，导出不删除源证据或释放容量。

- 无 UI 构建裁剪审计事件的展示缓存与广播，保留持久化审计、恢复校验、序号及 Required Audit 确认。
- 同步审计回调及普通 invocation 创建在多线程 Runtime 上让出执行器，保持原锁顺序、同步持久确认和错误处理。
- 异步授权将持久审计纳入既有有界阻塞 worker，MCP Task 等待授权时让出执行器；保留每条审计的落盘确认、配置／会话／预算复核及失败关闭。
- Qdrant 入库逐个 point 编码到同一个完整请求缓冲，减少整批 JSON 中间树和复制；保留原向量编码、签名及单次 upsert 行为，准备阶段失败或取消时不提前发送 points。
- MCP Task 准入复用一次请求 ID 编码和 owner Weak 引用，减少重复分配及原子引用计数操作；保留重复请求拒绝、容量、过期回收和失败释放语义。
- Native PII 电话候选在当前候选内复用完整解析对象相等的无效验证结果，保留地区解析顺序和有效结果短路；使用有界局部状态，保持检测规则、期限和取消检查。
- Native PII 电话检测使用小型 regex-cache 源码补丁，将 CachedRegex 命中的重复查找收敛为一次，保留匹配、容量、LRU 及锁语义；加入契约回归和发布包 MIT 许可。

- 增加纯端侧设备助手示例和回归：本地只读 MCP 工具 → 本地模型，启用离线 JWT、Agent 绑定、预算、PII 和持久化 Required Audit，不依赖云 SDK、数据库或 OTLP。
- 增加启动配置 `bindAddress`，统一本地 binds／LLM／MCP／A2A 监听地址选择，支持限制在回环地址；缺省行为及安全配置热更新语义保持。
- 支持按场景编译组合 LLM、MCP、A2A、RAG，保留共享 Host、安全配置热更新和统一受控执行。
- 提供 RAG → LLM 与知识检索 → 工具 → 模型 → A2A Task/Artifact 的示例链路。
- 严格拒绝未知安全字段；不支持内容检查的路径在出站前拒绝，响应 guard 默认检查流，非流式工具参数纳入检查和实际遮蔽。
- 旧 MCP stdio/SSE 关联限制为每连接 128 项和 120 秒期限，连接关闭与新注册保持同步；不自动重发不确定的副作用。
- A2A Task 绑定原 Context 与预算，同一用户不能用新 Context 接管旧 Task；旧 Task 缺少所需绑定时拒绝并要求新建。
- 移除 Runtime 演示事件注入；真实授权、拒绝和审计持久化保留。
- 移除未使用的 Rust `SecurityGateway` facade，嵌入方迁移至 `SecurityPipeline`；现用 Capability、安全控制及配置/API 保留。迁移方式见[配置参考](reference/configuration-guide.md#composable-security-pipeline)。
- 同步配置／Admin Schema 与源码，增加只读生成一致性检查。
- 修复非法 discovery 热更新留下监听的问题；MCP Session/Task 及流式续权执行双声明约束，安全声明下禁止原始元数据透传；PDP 缓存仅在显式启用时使用并限制容量。
- 修复响应 guard 对未知 SSE 文本字段的漏检，并独立检查已知引用／注解／logprobs；默认 RAG chunk ID 改为租户／corpus／文档范围内的稳定 UUID，保留已有 lifecycle ID。
- 审批 receipt 与绝对期限贯穿 Capability 签发和消费；限制票据有效期不超过审批期限，并拒绝错配或超期的签发响应。
- 修复 MCP 会话空闲续期、失败 Task 的本地资源释放和反向请求额度占用；进度通知只转发当前请求绑定的内容。
- 修复 RAG 文档传输预算、失败阶段审计、删除失败重试及主体字段透传；保留租户、文档权限和最终 Context 校验。
- 修复配置／依赖文件监听恢复、HTTP 资源刷新和 Listener 生命周期；启动专属配置变更明确要求重启，远程安全 Provider 配置在发布前预检。
- 收敛重复安全入口和请求处理，修复 Provider 路径编码并减少普通日志中的凭据暴露。
- Native PII启用电话检测时，在配置发布前通过阻塞准备初始化共享元数据和常见地区路径，减少首次检测阻塞；准备失败拒绝就绪，保留请求超时与检测规则，并提前驻留相应缓存。
- 优化预算创建的容量计数和按需回收，减少高占用时的重复扫描；持久化恢复重建同一索引，保留取消、耗尽、在途与清理宽限及落盘失败关闭语义。
- 加权模型路由在不可变配置中准备分布，减少每次选择的分配；PDP 缓存仅在可能到期时进行容量清扫，并减少同一绑定键的编码临时字符串，保留原有期限及默认 Fail-Closed。
- 提供可选 `security-rag-sqlite`，通过显式配置接入 RAG／LLM／MCP／A2A 的 Context／文档共同事务与恢复；保留原 JSONL，新增异步校验及逐帧提交后复核，修复嵌套读取与定时授权的事务等待互锁。提供显式离线 `import-rag-state`，保留源文件并拒绝覆盖已有目标。
- 提供五种场景的候选构建、版本/提交核验、manifest 和 SHA-256，不自动发布。见[发布指南](release/README.md)。

当前仍为 PoC 候选版本；真实设备、生产环境和完整外部服务集成需要进一步验证。变更记录不表示版本已经发布。
